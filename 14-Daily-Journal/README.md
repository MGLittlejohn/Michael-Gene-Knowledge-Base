# Daily Journal

The Daily Journal is the chronological capture layer of the knowledge base.

## Purpose
Use dated entries for:
- What happened today
- Work completed
- Measurements and observations
- Problems encountered
- Decisions made
- Things learned
- Follow-up items

## Naming
Use ISO-style dates so entries sort naturally:
`YYYY-MM-DD.md`

Example:
`2026-09-07.md`

## Distillation Rule
The journal records the day. Permanent subject folders preserve durable knowledge.

When a journal entry contains something worth keeping long-term:
- Faith/preaching insight → `01-Faith/`
- HVAC technical lesson → private `HVAC-Knowledge-Base`
- Vehicle history → `03-Vehicles/`
- Equipment history → `04-Equipment/`
- Property work → `07-Property/`
- Technology troubleshooting → `09-Technology/`

Do not duplicate the whole journal entry. Move or summarize the durable lesson into its natural home.

## Privacy
Because this repository is public, avoid sensitive medical, financial, family, account, address, credential, or other private information in journal entries.
