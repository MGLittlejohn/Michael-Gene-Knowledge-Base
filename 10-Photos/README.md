# Photos — Reference Index

This folder is for photographs that genuinely serve as shared reference material.

## Preferred Rule
Keep equipment and project photographs beside the records they document whenever practical. For example, an equipment identification-label photo is usually most useful inside that equipment's folder.

Use this central Photos section when:
- A photo applies to several subjects
- A general photo archive needs an index
- A project intentionally uses a central photo collection

## File Naming
Prefer descriptive names such as:
`2026-09-daikin-project-1-outdoor-unit-label.jpg`

rather than camera-generated names that reveal nothing about the subject.

## Privacy
Before placing a photo in this public repository, check the image for addresses, license plates, serial numbers that should remain private, paperwork, computer screens, faces, location clues, or other personal information.
