- Deer hunting

- Gear/setup notes

## Filing Rule
Keep durable knowledge here. One-day observations can first live in the Daily Journal and later be distilled into this section if they prove useful.

## Safety / Privacy
Avoid publishing exact private property locations, stand coordinates, gate codes, or other location details that should remain private.
