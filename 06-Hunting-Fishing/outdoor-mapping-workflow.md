# Outdoor Property Mapping Workflow

## Purpose
A repeatable workflow for creating useful hunting, wildlife, and land-management maps without storing sensitive stand coordinates or private parcel identifiers in this public repository.

## Workflow
1. Start with county GIS or another authoritative parcel/base-map source when boundaries matter.
2. Use a parcel/land mapping service such as Regrid when it adds useful visual context.
3. Add aerial imagery and terrain/topographic layers.
4. Mark broad features such as ridges, creeks, roads, fields, timber edges, funnels, access routes, and habitat transitions.
5. Keep exact stand locations, private access points, gate information, and other sensitive coordinates in a private working map rather than this public knowledge base.
6. Date exported maps so later habitat or access changes can be compared.

## Hunting Analysis Layer
When evaluating an area, consider:
- prevailing wind and thermals
- bedding-to-feeding travel
- terrain funnels and pinch points
- creek crossings
- edge habitat
- low-impact entry and exit routes
- seasonal food sources
- pressure from roads, houses, or neighboring access

## Filing Rule
Store the method here. Keep exact private-property coordinates and identifying parcel information out of the public repository.
