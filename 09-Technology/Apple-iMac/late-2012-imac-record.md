# Late-2012 27-inch iMac — System Record

## Hardware
- Model era: Late 2012
- Display: 27-inch
- Processor: 3.4 GHz quad-core Intel Core i7
- Memory: 32 GB DDR3
- Graphics: NVIDIA GeForce GTX 680MX, 2 GB

## macOS
The iMac has been operated with newer macOS through OpenCore Legacy Patcher (OCLP). A September 2026 working configuration recorded macOS Sequoia 15.7.9 with OCLP root patch v2.4.1.

## Boot / Linux Notes
A prior storage/boot record documented macOS and Linux Mint installations with EFI boot entries. When selecting operating systems at startup, hold Option and select the intended boot entry rather than changing partitions casually.

## September 2026 Desktop Incident
A temporary Finder/Desktop display problem made the normal desktop disappear. The desktop later returned. This did not establish a Linux/UTM installation failure, and Linux/UTM files were not treated as deleted.

## ChatGPT Note
The current official ChatGPT desktop application is not suitable for this older Intel Mac configuration. Official ChatGPT remains usable through the web browser, while the iPhone can be used for normal ChatGPT work.

## Preservation Rule
Do not erase, reinstall, repartition, or alter the Linux installation merely to troubleshoot an application-level UTM problem. Preserve the known working macOS and Linux data while diagnosing compatibility issues.
