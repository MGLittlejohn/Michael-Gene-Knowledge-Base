# ChatGPT + GitHub Knowledge-Base Workflow

## Connected Repositories
### Michael-Gene-Knowledge-Base
Role: master personal knowledge library.

Major categories include Faith, HVAC, Vehicles, Equipment, Shop, Hunting & Fishing, Property, Health, Technology, Photos, Manuals, Templates, Projects, and Daily Journal.

### HVAC-Knowledge-Base
Role: dedicated technical HVAC/MVAC library for polished procedures, troubleshooting, commissioning records, service reports, diagrams, tools, and teaching material.

## Working Architecture
Use the master repository for the broad personal record. Use the dedicated HVAC repository for detailed technical HVAC/MVAC material. Cross-reference where useful instead of needlessly duplicating large documents.

## Chat Workflow
Useful instructions during normal conversations include:
- `Mark this` — identify material worth preserving
- `That Will Preach` — preserve faith/theology/behavior material in the keeper collection
- `Put this in GitHub under Murano` — file vehicle-specific material
- `Save this under Daikin` — file HVAC project material
- `GitHub this` — determine a sensible permanent location and file it

## Safety / Filing Rules
- Read existing files before replacing or substantially reorganizing them.
- Avoid duplicate keeper material.
- Do not delete existing material without deliberate review.
- Do not guess model numbers, serial numbers, part numbers, torque values, fluid specifications, or other technical facts.
- The Michael-Gene-Knowledge-Base is public, so do not place private/sensitive information there casually.
- The HVAC-Knowledge-Base is the dedicated technical repository and may contain detailed field records.
