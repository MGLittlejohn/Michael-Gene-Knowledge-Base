## Filing Standard
Each equipment folder should grow into the same basic record:
1. Equipment identification
2. Model/serial information and label photos
3. Consumables, fluids, filters, belts, blades, chains, plugs, etc.
4. Routine maintenance
5. Repair/troubleshooting history
6. Parts and part numbers
7. Manuals and reference information
8. Dated service log

Exact specifications should be verified before being entered as permanent technical reference.
