# Templates — Reusable Forms

This section contains blank or reusable forms. Completed records belong with the vehicle, equipment, property, project, or subject they document.

## Template Types
- Equipment service record
- Vehicle service record
- Project record
- Troubleshooting worksheet
- Parts/shopping checklist
- Inspection checklist
- Maintenance log

## Rule
**Template = blank reusable pattern.**
**Record = completed history for a specific item.**

Do not store multiple nearly identical forms when one general template can serve several categories.
