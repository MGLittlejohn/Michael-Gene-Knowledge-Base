# Projects — Active Workbench

This folder is the cross-category workbench for projects that are active, planned, or temporarily waiting and do not fit cleanly inside one permanent subject folder.

## Status Labels
- **PLANNED** — defined but not started
- **ACTIVE** — work underway
- **WAITING** — waiting on parts, weather, information, or another dependency
- **COMPLETED** — finished and verified

## Filing Workflow
1. Start a project here when it spans several categories or needs a temporary central workspace.
2. Keep the project plan, shopping/parts status, measurements, decisions, and work log together.
3. When complete, preserve the project history here if useful.
4. Copy or summarize reusable lessons into the permanent subject area rather than duplicating the entire project everywhere.
