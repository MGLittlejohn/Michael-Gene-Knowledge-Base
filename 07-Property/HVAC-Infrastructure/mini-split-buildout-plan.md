# Home Mini-Split Buildout — Property Plan

## Overall Plan
Five indoor units are planned across the home.

### Downstairs
- Project 1: Daikin 24K — great room / primary open living area — completed September 2026
- Project 2: Daikin 9K — living room, aimed to support airflow toward kitchen — planned
- Project 3: Daikin 9K — master bedroom, airflow toward vanity/bathroom — planned

### Upstairs — Later Phase
- Two 9K indoor units planned as the eventual replacement strategy for the existing upstairs 2-ton system

## Property Infrastructure
Preparation for the downstairs systems included:
- New electrical subpanel work
- Dedicated branch circuits
- Outdoor disconnects and whips
- Condenser pads
- Surge protection
- Line-set routing / line-hide planning

## Project 1 Result
The 24K system was installed, pressure-tested, evacuated, commissioned, and placed into successful operation in September 2026.
