# Driveway Material Plan

## Project
Driveway resurfacing/maintenance using crusher run or similar compactable aggregate.

## Planning Snapshot
- Estimated target quantity discussed: approximately 90 tons
- Example quoted material price: $19.60 per ton
- Material-only estimate at that snapshot: approximately $1,764 before tax, delivery, hauling, spreading, compaction, or other charges
- Quarry travel was estimated at roughly 20 minutes for hauling planning

## Before Ordering
Verify:
- Current driveway dimensions and desired finished depth
- Material type and gradation
- Current price per ton
- Truck/trailer legal payload
- Delivery versus self-haul economics
- Number of loads
- Base condition and drainage
- Spreading and compaction plan
