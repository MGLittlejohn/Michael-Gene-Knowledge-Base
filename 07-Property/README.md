# Property — Master Index

Permanent records for home/property infrastructure, electrical work, driveway work, utilities, outdoor improvements, and recurring property-maintenance projects.

## Current Sections
- `Electrical/` — panels, subpanels, branch circuits, disconnects, surge protection, and electrical project records
- `Driveway/` — crusher-run / crushed-concrete planning, quantities, costs, hauling, and maintenance
- `HVAC-Infrastructure/` — property-side infrastructure supporting the mini-split buildout; detailed refrigeration/HVAC technical procedures remain in the private `HVAC-Knowledge-Base`

## Filing Rule
Keep property-specific facts here. Keep polished HVAC/MVAC technical procedures in the dedicated HVAC repository. Cross-reference rather than duplicating large technical documents.

## Privacy Rule
Do not store unnecessary home-address, account-number, utility-account, or other identifying information in this public repository.
