# Health & Fitness

This section is reserved for general wellness, exercise, fitness programming, and non-sensitive reference material.

## Public-Repository Rule
This repository is public. Do **not** store private medical diagnoses, medical records, medications, insurance/account information, test results, provider information, or other sensitive personal health details here.

## Appropriate Material
- General exercise programs
- Strength-training principles
- Mobility and conditioning references
- Equipment setup notes
- General nutrition/fitness education
- Blank workout templates

## Better Home for Sensitive Information
Personal medical information should remain in an appropriate private system rather than this public GitHub repository.
