# Manuals — Reference Library

Use this section as an index/reference shelf for manufacturer manuals, installation instructions, service literature, specification sheets, and other authoritative documentation.

## Filing Rule
Whenever practical, keep a manual close to the equipment or project it serves and place an index/reference here. Avoid storing several identical copies of the same large manual.

## Suggested Categories
- Vehicles
- Outdoor equipment
- HVAC equipment
- HVAC tools and instruments
- Electrical equipment
- Computers / technology
- Household equipment

## Source Discipline
For permanent technical values such as capacities, torque specifications, fluid types, service intervals, wiring, refrigerant procedures, and safety requirements, prefer the correct manufacturer manual for the exact model/serial range.

## Privacy / Copyright
Do not place private account documents or unnecessary personal information here. Prefer links/citations or legitimately retained personal copies of manuals rather than reproducing copyrighted material unnecessarily.
